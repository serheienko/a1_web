# taste-skill (внешний скилл, положен 19.09.2026)

Что это: инструкция по дизайну фронтенда для ИИ-агента. Один текстовый
файл SKILL.md, ничего не запускается и никуда не ходит. Агент читает его
перед тем, как делать страницу, и следует правилам.

Откуда: github.com/Leonxlnx/taste-skill, лицензия MIT (файл LICENSE рядом).
Взят коммит от 19.09.2026, файл skills/taste-skill/SKILL.md без изменений.
Обновлять — просто перекачать тот же файл.

Зачем взяли (Александр, 19.09.2026, после рилса romarayt): чтобы новые
промо-страницы не выглядели «сделано нейросетью» — скилл запрещает
типовые признаки (фиолетовый градиент, три одинаковые карточки,
Inter + тёмно-серый, бесконечные анимации) и заставляет сначала вслух
определить, что за страница и для кого.

ГДЕ ПРИМЕНЯТЬ: /download, будущие посадочные под SEO, промо-страницы,
редизайн лендинга a1appp.com.

ГДЕ НЕ ПРИМЕНЯТЬ: лента вакансий, карточки, фильтры, формы, чаты,
админка. Сам скилл первой строкой пишет, что он не для этого («не
дашборды, не таблицы, не многошаговый интерфейс продукта»), а у нашего
сайта уже есть свой устоявшийся стиль — тёмная тема, Montserrat, готовые
компоненты. Тянуть туда «награждённую» эстетику нельзя.
